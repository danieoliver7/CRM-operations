# Anti Patterns

## Avoid Right Now

- backend-first development
- workflow engines
- realtime systems
- excessive Zustand usage
- enterprise abstractions
- over-normalized architecture
- microservices
- AI features too early
- excessive automation

## Avoid In UI

- dashboard pollution
- too many warnings
- generic enterprise visuals
- excessive charts
- giant components

## Avoid In State Management

- global UI state
- event buses
- orchestration layers
- runtime managers
