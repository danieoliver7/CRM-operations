# Design System

A interface segue estilo:
- Linear
- Vercel
- Notion
- Stripe

Características:
- dark mode premium
- minimalista
- enterprise SaaS
- foco operacional
- baixa distração visual

A interface deve parecer:
- rápida
- limpa
- moderna
- colaborativa

Evitar:
- excesso de cores
- gradientes exagerados
- sombras fortes
- excesso de bordas
