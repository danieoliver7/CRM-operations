# Operational UI Patterns

## Operational Cards

Cards should:
- expose operational state
- communicate pressure
- highlight next action

---

# Operational Warnings

Warnings should:
- remain subtle
- avoid pollution
- prioritize clarity

---

# Workflow Components

Workflow components should:
- guide operations
- expose next steps
- remain contextual

---

# Dashboards

Dashboards should:
- support operations
- avoid BI complexity
- avoid generic analytics

---

# Calendar

Calendar exists for:
- operational planning
- workload visibility
- campaign coordination

NOT:
- generic scheduling
